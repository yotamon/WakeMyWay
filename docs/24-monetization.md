# Monetization direction

## Principle

Wake My Way can support subscription economics because waking is a high-frequency habit and AI voice has ongoing costs.

However, monetization must never compromise trust during the wake session.

## Hard rules

- no advertisements while an alarm is active
- no paywall during a wake session
- subscription failure cannot prevent a scheduled alarm from ringing
- free users retain a reliable base alarm
- never exploit half-awake accidental taps for upsell

## Early pricing hypothesis

Discovery-stage range discussed:

```text
€4.99/month
~€39/year
```

This is a hypothesis, not a locked price.

## Possible packaging

### Free

- reliable alarm kernel
- one basic character/scripted behavior
- reliable deterministic Wake Runtime
- basic local adaptation as needed to prove the core product promise
- local alarm functionality

### Pro

Potentially:

- full realtime conversational wake experience
- premium voice/character options
- all characters
- advanced Tomorrow Contract
- richer contextual orientation
- advanced wake strategy modes

## Voice cost control

Define provider budgets regardless of plan:

- max live session time
- turn limits
- retry limits
- local fallback threshold

Do not create a product where successful waking requires an unbounded inference bill.

## When to implement billing

Do not prioritize billing before dogfood and initial retention evidence.

First prove:

1. alarms are trusted
2. WMW improves wake outcomes
3. users return voluntarily
4. conversational/adaptive features are valued
